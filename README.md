# 🌐 Simple Responsive Webpage Using Tailwind CSS


## 💡 Features

- **Responsive Layout** — Works across mobile, tablet, and desktop.
- **Tailwind CSS** — Clean and maintainable utility-first styling.
- **Sticky Header** — Persistent top navigation bar.
- **Hero Section** — Bold banner with heading and background imagery.
- **Features Section** — Alternating text-image layout with lorem text.
- **Gallery Section** — Grid of image cards with preview overlays.
- **Swiper Carousel** — Testimonial cards powered by Swiper.js.
- **Contact Form** — Includes email and message inputs.
- **Footer** — Simple copyright.

## 🛠️ Tools & Technologies

- **Tailwind CSS**
- **HTML5**
- **JavaScript (for Swiper.js)**

## 🚀 Getting Started

- **npm install -D tailwindcss**
- **npx tailwindcss init**
